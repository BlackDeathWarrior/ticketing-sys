This page stands in for the website of an app connected in Settings → Integrations. It loads the widget with that integration, your colours and wording, and what the visitor is looking at: 

TMSChat.init({
  integration: 'your-integration',
  theme: { primary: '#7a1f3d' },
  strings: { launcher: 'Need help?', title: 'Ask us' },
  context: { product_id: 'DEMO-1001' },
  on: { ticket: (t) => console.log('opened', t.reference) },
});

Add ?integration=<identifier> to this page's address to try it with one of yours. Optional: primary, position (left), product, name, and server when the helpdesk is on another address.
