# Cancellations, returns and refunds

## Cancelling an order

You can cancel an order until it ships, that is, while it is "Order placed" or "Packed". Open the order under "Your Orders" and choose "Cancel order". If you had already paid, the full amount is refunded at once. If you chose cash on delivery, nothing was charged.

## An order that has already shipped

An order that has shipped cannot be cancelled. Wait for it to arrive and return it.

## Returning an order

You can return an order within 7 days of delivery. Open the order and choose "Return items", and say what is wrong. The return is then reviewed, and the refund follows once it is approved.

## Refunds

A refund is always for the full amount you paid, to the payment method you used. It reaches you in 5 to 7 business days. The order page shows the refund reference, which starts with "RF-".

## Wrong or damaged items

If an item arrives damaged or is not what you ordered, choose "Get help with this order" on the order page and pick "Wrong or damaged item". Support arranges the return and the refund.
