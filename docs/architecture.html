    Design decisions this map commits to

    One controller per conversation

    The orchestrator records whether the AI or a named agent owns each live conversation. Takeover is a single state change, so the AI and an agent never reply at the same time.

    Covers §8 handover, §10 live takeover

    AI reaches systems only through the Tool Gateway

    The model never holds credentials. Each tool has a schema, auth, a risk tier, timeouts and an audit record. Transactional tools wait in the approval queue.

    Covers §6 tools, §14 governance

    Channels are adapters

    Each channel converts to one message envelope at the gateway. Everything downstream is channel-agnostic, and a new channel means one new adapter.

    Covers §3 channels, §16 future channels

    Handover carries a context pack

    Summary, intent, actions taken, tools used, data retrieved and a recommended next step travel with the conversation, so the customer never repeats the issue.

    Covers §8 handover context, §9 agent UI

    Events feed reporting and audit

    Services publish ticket and conversation events to one stream. Reporting, notifications and audit consume it instead of querying live services.

    Covers §12 notifications, §13 reporting
